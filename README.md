# 역삼의 밤 · Yeoksam After Hours

역삼역의 밤거리를 배경으로 만든 싱글 플레이 2D 웹 액션 RPG 프로토타입입니다. 플레이어는 제공된 만화 속 펭귄 또는 회색·흰색 고양이를 고를 수 있습니다. 로봇, 스킬 수치, 지역은 프로토타입 설정입니다. 실제 역삼역 지형을 정확히 재현한 지도는 아닙니다.

## 실행

Python 3가 설치된 환경에서 이 폴더를 열고 실행합니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. Node.js가 있다면 `npm start`도 가능합니다. 패키지 설치나 빌드는 필요하지 않습니다. JavaScript 모듈을 사용하므로 HTML 파일을 더블 클릭하지 말고 HTTP 서버로 실행하세요.

## 조작

| 입력 | 동작 |
| --- | --- |
| 방향키 | 위·아래·왼쪽·오른쪽 이동 |
| Space | 점프. 기본형은 귀여운 도약, 근육형은 힘찬 도약. 이동과 함께 눌러 대각선 점프 |
| A | 기본 공격. 누르고 있으면 연속 공격 |
| Q | 펭귄 펀치. Lv. 3 / MP 8 |
| W | 배치기 돌진. Lv. 7 / MP 12 |
| E | 전직 후 Lv. 10: 바디빌더 회복 / 검사 막기. MP 18 |
| R | 전직 후 Lv. 15: 바디빌더 근육 각성 / 검사 섬광 연참. MP 30 / 재사용 바디빌더 40초 · 검사 30초 |
| M | 전체 월드맵 열기 / 닫기 · 상세 안내 탭에서 기존 경로 지도 |
| F | 가까운 NPC 대화 또는 포탈 이동 |
| 1 / 2 / 3 | 등록된 아이템 사용. 처음에는 1번에 체력 물약 |
| I | 인벤토리 열기 / 닫기. 아이템 선택 후 숫자키 또는 슬롯 클릭으로 등록 |
| Esc | 메뉴 / 창 닫기 |

좁은 화면에는 이동·점프·공격·대화·물약 터치 버튼이 표시됩니다. 스킬은 하단 버튼으로도 사용합니다. 대화·가방·메뉴를 여는 동안 게임은 일시정지합니다.

## 플레이 흐름

1. 시작하기 → 새 캐릭터 생성 → 이름 입력.
2. 캐릭터 더블 클릭 또는 선택 후 모험 시작하기 → 로딩 → 입장.
3. 처음에는 마을에서 HP 100, MP 60, 500원, 체력 물약 3개로 시작합니다.
4. 파란색 `ssafy` 글자가 있는 흰색 후드와 선글라스를 착용한 펭귄 현토리가 게임을 안내하고, 시크한 표정에 마법사 모자를 쓰고 가방과 보따리를 곁에 두고 나무 상자 위에 앉아 있는 개구리 마구리가 체력 물약(50원)과 역삼역·강남역 귀환 주문서(기본 100원, 역삼역에서 판매하는 강남역 귀환 주문서는 1,500원)를 판매합니다.
5. 마을 오른쪽에는 피치플레이, 역삼역사거리, 테헤란 뒷골목 포탈이 있습니다. 사거리(Lv. 1~3)를 건너면 6번 출구와 강남성균검도관으로 이어집니다.
6. 던전 오른쪽 끝 포탈 → 불 꺼진 공사장(Lv. 4~8). 권장 레벨보다 낮으면 확인 창이 표시됩니다.
7. 로봇 처치 시 경험치, 돈, 부품/코어를 얻습니다. 물약은 확률적으로 추가 드롭됩니다. 떨어진 물건에 가까이 가면 자동 획득합니다.
8. 레벨 상승 시 능력치 증가, HP·MP 완전 회복. Q는 Lv. 3, W는 Lv. 7에 습득합니다. 전직 후 E와 R을 배웁니다.
9. HP 0이면 부활 화면 → 마을에서 완전 회복합니다. 돈·경험치·레벨·아이템 손실이 없습니다.

M을 누르면 그림 배경 위에 17개 지역과 실제 포탈 연결을 표시하는 **전체 지도**가 먼저 열립니다. 현재 위치는 별도 표식으로 유지하고, 지역을 선택하면 현재 위치부터 목적지까지의 최단 경로를 노란색으로 강조합니다. 내 위치 찾기 버튼은 지도만 현재 지역으로 맞춥니다. 작은 화면에서는 지도를 좌우로 스크롤합니다.

**상세 안내** 탭에는 기존의 초반 사냥 / 고레벨 던전 / 마을·전직 목록을 유지합니다. 추천 사냥터, 몬스터 수, 다음 포탈의 방향·순번과 연결 지역을 확인할 수 있습니다. 두 보기의 목적지 선택은 공유되며, 지도를 닫았다 열면 전체 지도와 현재 위치를 다시 표시합니다. 실제 이동은 게임 안의 포탈에서 F로 합니다.

`WORLD_MAP_LAYOUT`은 읽기 쉬운 배치이며 실제 지리적 위치나 거리를 뜻하지 않습니다. 연결선은 `MAPS`의 포탈에서 중복을 제거해 생성합니다. `world-map.png`는 imagegen으로 만든 새 배경이고 텍스트·연결선·선택 표시는 HTML/SVG로 그립니다. 생성 프롬프트는 `world-map-art-prompt.txt`에 있습니다.

MP는 초당 2.2 회복됩니다. 마을에서는 HP도 초당 6 회복됩니다. 점프가 충분히 높을 때 접촉 피해를 피할 수 있습니다. 기본 공격은 방향과 거리를 맞춰야 합니다.

## 성장과 전직

레벨 1→10 구간의 레벨업 필요 경험치는 기존 요구량의 60%인 `48 × 현재 레벨`입니다. 레벨 10→11부터는 기존의 `80 × 현재 레벨`을 유지합니다. 1→10의 총 필요 경험치는 3,600에서 2,160으로 줄었습니다. 몬스터 보상은 그대로입니다. 기존 캐릭터는 저장된 경험치가 새 요구량을 넘으면 접속 시 레벨을 올리고 남은 경험치를 보존합니다. 레벨 10에 도달해도 E 스킬은 전직 후에 배웁니다.

Lv. 10 이상에서 해당 장소의 NPC에게 F로 말한 뒤 전직을 선택합니다. 캐릭터당 한 번 선택하며 다른 직업은 새 캐릭터로 플레이할 수 있습니다. 기존 캐릭터는 미전직 상태로 시작하며 레벨이 충분하면 바로 전직할 수 있습니다.

| 장소 | 직업 | Lv. 10 E | Lv. 15 R |
| --- | --- | --- | --- |
| 피치플레이헬스&필라테스 역삼점 · 근육 코치 | 바디빌더 | 1.5초간 HP 40% 지속 회복 · 피해 50% 감소 | 12초간 거대화·스킬 강화 |
| 강남성균검도관 · 검도 사범 | 검사 | 1초 공격 차단 · 방어 중 공격/스킬 사용 불가 | 최대 5명 순간이동 연속 베기 |

강남성균검도관은 역삼역 1번 출구 → 역삼역사거리(몬스터) → 역삼역 6번 출구를 거쳐 이동합니다. 피치플레이헬스&필라테스 역삼점은 1번 출구와 직접 연결됩니다. 헬스장–검도관 포탈은 없습니다. 지도 M에서 경로를 볼 수 있습니다. 직업은 캐릭터마다 저장되며 사망·맵 이동·재접속 후 유지됩니다. E/R은 레벨 조건과 전직 조건을 모두 만족해야 합니다.

검사의 R은 키보드나 스킬 버튼을 누르는 동안 가까운 적부터 0.6초마다 조준합니다. 첫 적은 즉시 조준하며 현재 맵 전체에서 최대 5명을 지정합니다. 거리와 상하 위치에 따른 사거리 제한은 없으며 다른 맵의 적은 포함하지 않습니다. 손을 떼거나 3초가 되면 각 적에게 0.16초 간격으로 순간이동해 공격력 7배의 피해를 줍니다. 발동 순간 살아 있는 조준 대상이 한 명이면 피해가 2배(공격력 14배)가 됩니다. 조기 발동과 보스에게도 적용되며, 여러 명으로 발동한 뒤 대상이 죽어도 피해 배율은 바뀌지 않습니다. 이동과 다른 공격은 연출 동안 잠깁니다. 조준 대상이 없으면 자원을 쓰지 않습니다. 메뉴·지도·맵 이동·사망·탭 전환은 기 모으기와 남은 베기를 취소하며 이미 쓴 MP/쿨다운은 돌려주지 않습니다. 죽은 대상은 건너뛰며 중복 보상은 없습니다. 접근성 키보드의 스킬 버튼 활성화는 3초 자동 충전으로 동작합니다.

검사의 궁극기를 충전하면 화면이 약 0.58배까지 축소되어 기본 시야보다 약 1.7배 넓은 범위를 보여 줍니다. 작은 화면, 멀리 떨어진 적을 조준하거나 피격으로 위치가 밀리는 상황에서는 조준 표시가 들어오도록 더 넓어집니다. 맵 양 끝의 조준 표시가 잘리지 않도록 궁극기 카메라는 맵 바깥까지 비출 수 있습니다. 카메라는 시작 위치를 중심으로 유지하므로 연속 순간이동 때마다 따라 튀지 않습니다. 충전 중에는 약한 진동, 발동과 베기에는 더 큰 진동이 적용됩니다. 타겟 번호 없이 조준 표시만 화면에서 같은 크기를 유지하며 HUD는 축소하지 않습니다. 정상 종료 후에는 부드럽게 복원하고, 메뉴·맵 이동·사망·탭 전환 등 취소 시에는 즉시 복원합니다. 돌진 궤적은 검은 외곽선·노란 잔광·밝은 중심선과 도착 섬광으로 강조됩니다. 단일 대상 발동은 궤적과 베기 섬광도 더 강하게 표시합니다. 검사의 W도 실제 이동 경로를 따라 굵은 직선 궤적을 남깁니다.

## 점프 모션

기본형은 짧게 웅크린 뒤 양팔을 펼치고 발을 모아 뛰며 웃는 표정으로 착지합니다. 근육 각성 중에는 무릎과 주먹을 들어 올려 힘차게 도약하고 낮은 자세로 착지합니다. 두 모습 모두 준비·도약·상승·정점·하강·착지의 6가지 그림을 실제 점프 높이와 속도에 맞춰 재생합니다. 짧은 준비 동작은 0.065초이며 공중 이동과 공격은 계속 조작할 수 있습니다. 착지 후 대기 또는 걷기로 이어지고, 덤벨과 칼집도 각 자세의 손과 허리를 따라갑니다.

## 장비와 인벤토리

바디빌더는 전직 즉시 핑크 덤벨을 들고, 검사는 칼집에 든 일본도를 허리에 찹니다. 덤벨은 평상시와 근육 각성 상태 모두 표시되며, 걷기·점프 프레임의 손 위치와 점프 높이를 따라갑니다. 장비 외형은 직업에서 결정하며 별도 능력치를 추가하지 않습니다.

I로 인벤토리를 열어 소모품과 수집 재료를 봅니다. 소모품을 선택한 뒤 1·2·3키 또는 해당 슬롯을 눌러 등록합니다. 슬롯 비우기와 직접 사용도 지원합니다. 등록은 캐릭터별로 저장되며 재료는 등록하지 못합니다. 사용하여 수량이 0이 되어도 슬롯 등록은 남습니다. 동일 아이템을 여러 슬롯에 등록할 수도 있습니다.

귀환 주문서는 1개를 소모해 역삼역 1번 출구로 즉시 이동합니다. HP·MP·직업·경험치·재사용 대기를 유지하고 현재 전투와 점프를 종료합니다. 마을 또는 수량이 없는 상태에서는 소모하지 않습니다. 수량 감소와 마을 좌표를 함께 저장합니다. 기존 저장 파일의 물약·전리품은 보존하고 새 항목과 슬롯을 안전하게 추가합니다.

## 바디빌더 근육 각성

평소에는 하늘색 후드를 입은 평범한 펭귄입니다. 바디빌더 전직 후 Lv. 15부터 R을 쓰면 주변에 충격파를 만들고 12초 동안 큰 근육질 펭귄으로 변신합니다.

| 행동 | 변신 중 강화 |
| --- | --- |
| A | 피해 1.8배, 공격 범위와 속도 증가 |
| Q | 피해 2배, 범위 1.5배, 재사용 시간 절반 |
| W | 피해 2배, 돌진 거리 1.6배, 재사용 시간 절반 |
| E | 1.5초간 최대 HP 70% 회복, 피해 50% 감소, 재사용 시간 절반 |

변신 시 이미 진행 중인 Q/W/E 재사용 대기 시간도 절반으로 줄어듭니다. 지도·메뉴·숨겨진 탭에서는 변신 시간이 멈춥니다. 맵 이동에서는 남은 변신 시간과 재사용 대기를 유지합니다. 사망·캐릭터 재선택·새로고침 후에는 기본 모습으로 돌아오지만 재사용 대기는 저장합니다. 따라서 포탈 이동이나 재접속으로 궁극기를 바로 다시 사용할 수 없습니다.

총 17개 지역이 있습니다. 스카이루프 → 중계소 → 냉각수로 → 주조소 → 중앙 제어실로 사냥을 이어갑니다. 새 던전은 기존 6마리보다 많은 8–10마리가 등장하며 위치·레벨을 지역 범위에 맞춰 분산합니다. 몬스터는 처치 12초 후 플레이어와 거리를 두고 다시 나타납니다. 필요 경험치와 기존 보상 공식은 유지합니다. 모든 포탈은 왕복 가능하며 M 지도의 지역 설명에서 포탈 위치를 확인할 수 있습니다.

## 군인 승현 중간보스

자동화 주조소(Lv. 21–24)에서 강남역 마을로 이동한 뒤 오른쪽 빨간 보스 포탈로 **한사발포차 역삼점**에 들어갑니다. 보스 가까이에서 F로 대화한 뒤 결투 시작을 누르세요. Lv. 25, HP 30,000이며 권장 도전 레벨은 20–25입니다. 전투 중 안전 구역의 HP 자동 회복과 출구 포탈은 멈춥니다. Esc 메뉴에서 포기하거나 귀환 주문서로 빠져나올 수 있습니다. 포기·귀환·사망·재접속 후에는 보스가 최대 HP의 대기 상태로 돌아갑니다.

보스 테스트는 대화 후 시작, 패턴 횟수, 벽의 기습 방향과 착지 고정, 점프/막기/무적 판정, 물약 경로 공통 제한 및 일시정지, 보상 중복 방지, 군복 저장·배수, 포기·귀환·죽음·재입장 초기화, 비행 중 검사 궁극기 대기를 확인합니다. Lv.25 강화 후에는 반격 예고/유지/종료, 모든 타격 경로의 역피해, 반격 사망 저장과 궁극기 취소, 빠른 연타 5회, 장풍 양방향 스윕과 단일 피격을 함께 확인합니다. 수치는 실제 플레이에 맞춰 조정할 수 있습니다.

## 직업 특성

- 검사는 전직 후 기본 이동속도가 10% 증가합니다. 네 방향·대각선·공중 이동에 적용되며, 군복과는 곱연산해 1.32배가 됩니다. W 돌진·순간이동·넉백 거리는 바뀌지 않습니다.
- 바디빌더는 평상시와 근육 각성 중 받는 피해가 10% 감소합니다. 일반 몬스터 접촉 및 보스 검격·장풍·연타에 모두 적용하며 피해는 정수로 반올림합니다.
- 직업에서 보너스를 계산하므로 기존 저장 캐릭터도 즉시 적용됩니다. 전직 안내·인벤토리에서 특성을 확인할 수 있고, 상태창 직업 이름에 마우스를 올리면 표시됩니다.

## 화면 배치

- 큰 화면의 상태창은 HP·MP·EXP를 각각 한 줄에 표시하고 스킬·아이템 바와 지도 이름, 저장 영역의 여백을 줄였습니다.
- F로 여는 NPC 대화·상점·전직·보스 도전 안내는 오른쪽 아래의 작은 패널에 표시합니다. 긴 내용은 패널 안에서 스크롤하고, 운영자의 추가 안내는 펼쳐서 읽을 수 있습니다.
- NPC 대화의 배경 흐림을 없애고 높이를 화면의 65% 이하로 제한했습니다. 대화 중 일시정지, Esc 닫기, 키보드 포커스 처리는 유지합니다.

지원 브라우저에서는 WebMCP로 진행 상황 조회와 수동 저장이 가능합니다. 미지원 브라우저의 일반 플레이에는 영향이 없습니다.

## 후속 확장

최종 캐릭터 디자인, 스킬 기획, 추가 던전과 장비 시스템을 확장할 수 있습니다. 걷기는 기본형과 근육형 각각 8프레임 시트를 재생합니다. 실제 지상 이동 거리로 주기를 계산하며, 근육형의 보폭은 더 크게 설정했습니다. 점프·대시·순간이동·피격 밀림·벽에 막힌 입력은 걷기 주기에 포함하지 않습니다. 이동을 멈추면 기본 대기 이미지로 돌아옵니다. 멀티플레이, 서버 저장, 장비 강화, 퀘스트, 최종 사망 패널티는 포함하지 않았습니다.

## 강남역 마을과 두 종류의 귀환 주문서

- 이동 경로: **자동화 주조소 ↔ 강남역 ↔ 한사발포차 역삼점**. 기존 냉각수로 ↔ 보스방 포탈은 삭제했고, 주조소 ↔ 중앙 제어실 사냥 경로는 유지합니다.
- 강남역은 몬스터가 없는 안전 마을입니다. HP가 자연 회복되며 마구리에게 물약과 두 종류의 귀환 주문서를 구입할 수 있습니다. M 전체 지도와 상세 안내 모두 실제 연결을 반영합니다.
- 역삼역 1번 출구 귀환 주문서는 100원입니다. 강남역 귀환 주문서는 역삼역 상점에서 1,500원, 강남역 상점에서 100원입니다. 인벤토리 사용과 1·2·3 단축키 등록을 지원하며, 귀환 자체로 HP·MP는 회복되지 않습니다. 같은 목적지에 있을 때만 소모되지 않고, 두 마을 사이에서도 사용할 수 있습니다.
- 기존 저장의 `returnScrolls` 수량과 단축키는 역삼역용으로 그대로 유지합니다. 새 `gangnamScrolls`는 이전 저장에서 0개로 시작합니다. 저장 버전과 기존 캐릭터 ID는 바뀌지 않습니다.
- 강남역 귀환 위치는 (650, 648)입니다. 보스전에서 어느 주문서든 사용하면 전투·투사체·물약 대기·검사 궁극기를 정리하고 지정된 마을로 귀환합니다. 사망 시 부활 위치는 기존 역삼역 1번 출구를 유지합니다.
- `gangnam.png`는 기존 도시 화풍을 참고해 만든 게임용 야경입니다. 실제 강남역 출입구의 정밀 재현은 아닙니다. 생성 프롬프트는 `gangnam-prompt.txt`에 있습니다.


## 전투 동작과 방어 효과

- 기본 A와 Q에는 펀치 또는 검을 크게 휘두르는 4단계 동작이 표시됩니다. 전직 전 W는 배치기, 바디빌더 W는 어깨 돌진, 검사 W는 발도 돌진입니다. W의 기존 거리와 타격 판정은 유지하며 캐릭터 그림은 출발점에서 목적지까지 빠르게 이어서 움직입니다.
- 검사 E는 칼을 몸 앞에 세워 정확히 1초 방어합니다. A/Q/W/R과 스킬 버튼 입력을 막고, 실패한 입력에 MP나 재사용 대기를 소모하지 않습니다.
- 검사 R의 숫자 표시는 없애고 조준 원만 유지합니다. 충전과 연속 베기 모두 받는 피해 80% 감소가 적용됩니다. 연속 베기에 별도 무적은 추가하지 않습니다.
- 바디빌더 E는 X자 방어로 1.5초간 피해를 50% 줄이며 HP 40%(근육 각성 중 70%)를 시간에 나누어 회복합니다. 최대 HP에서도 방어 목적으로 사용할 수 있습니다. 직업의 기본 피해 10% 감소와 곱으로 적용하므로 원래 피해 100은 45가 됩니다. 회복 중 일반 공격과 다른 스킬은 사용할 수 없습니다. 이동속도는 평소의 60%가 되며, 팔을 X자로 막은 채 발을 번갈아 옮기는 전용 걷기 모션을 사용합니다. 일반·근육 형태와 군복 모두 적용됩니다. 회복이 끝나거나 맵을 떠나면 감속과 방어 효과도 끝납니다.
- 근육 각성 중에는 펀치·어깨 돌진·X자 방어가 대기 자세의 머리·몸 비율을 유지하는 근육 펭귄 전용 그림으로 전환됩니다. 스킬 자세를 그리는 동안 평상시 장비를 중복으로 표시하지 않습니다.
- 모든 일반 로봇은 피격 방향으로 몸이 젖혀지고 눌렸다가 돌아옵니다. 처치 순간에도 0.28초간 기울어지며 사라집니다. 보스의 피격 동작은 변경하지 않았습니다. 공격과 적중에는 짧은 화면 진동을 표시합니다. 바디빌더의 A·Q는 흰색과 옅은 하늘색의 주먹 바람·충격파, W는 같은 톤의 직선 돌진 궤적, R은 흰색 충격파와 하늘색 변신 오라를 사용합니다. 근육 변신 중에도 동일한 색상과 효과를 유지하며, 검사는 노란 번개를 사용합니다. 전직 전에는 A·Q 펀치와 W 배치기 동작, 몬스터 피격 동작과 회색 피해 숫자만 표시하며 번개·발광·돌진 잔상을 만들지 않습니다.
- `dist/assets/combat-brawler.png`(16프레임), `combat-swordsman.png`(12프레임), `combat-power.png`(12프레임)는 기본 imagegen 도구로 생성했습니다. 각 `combat-*-prompt.txt`가 정확한 생성 프롬프트입니다. 원본 PNG는 보존하며, 렌더러가 각 프레임의 몸 중심과 발 위치를 맞추고 겹치는 인접 검 이미지를 분리해 캐시에 보관합니다.


## 군복 외형

인벤토리에서 군복을 장착하면 기본 펭귄은 카키색 위장무늬 상의와 원래의 어두운 하의를 입습니다. 검사와 바디빌더의 대기·피격·걷기·점프·공격·방어 모션에 적용되며, 근육 각성 상태의 기존 군복 외형은 그대로 유지합니다. 일본도와 핑크 덤벨은 기존 위치에 표시되며 군복을 벗으면 원래 옷으로 돌아갑니다. 캐릭터 선택 카드와 입장 화면, 상태창의 초상화에도 장착 상태가 반영됩니다.

기존 `uniform`/`uniformEquipped` 저장값을 그대로 사용합니다. 소유만 하고 장착하지 않은 캐릭터는 원래 모습이며, 이동속도 +20% 효과와 사망·재접속 시 장착 유지 규칙은 동일합니다. NPC·일반 몬스터·보스 외형에는 적용하지 않습니다. `uniform-*.png`는 기존 플레이어 그림을 imagegen으로 편집한 군복 전용 시트입니다. 초기 프롬프트는 `uniform-art-prompts.json`, 기본 모습의 하의를 복원한 7개 시트의 편집 프롬프트는 `uniform-top-art-prompts.json`에 보관합니다. 전투 프레임 캐시는 이미지 객체별로 분리하여 장착·해제 시 이전 복장이 남지 않게 합니다.


## 검사 락온과 방어 이동, 돌진 궤적

- 검사 R의 타겟 표시는 검은 테두리와 노란 분할 원·모서리로 구성합니다. 줌아웃 중에도 화면에서 같은 크기를 유지하며 살아 있는 타겟의 위치를 따라갑니다. 숫자는 표시하지 않습니다. 충전 원도 같은 노랑·검정 조합입니다.
- 검사 E 중 실제 지상 이동이 있으면 검을 두 손으로 막아 든 채 8프레임 걷기를 재생합니다. 정지·벽에 막힘·공중에서는 제자리 방어로 돌아가고, 1초가 끝나면 평소 동작을 이어갑니다. 군복에도 적용하며 공격 제한과 방어 판정은 유지합니다. `sword-guard-walk.png`와 `uniform-sword-guard-walk.png`는 imagegen으로 만든 별도 시트이며 생성 프롬프트는 `guard-walk-art-prompts.json`에 있습니다.
- W는 부채꼴 대신 출발점부터 실제 도착점까지 검정·노랑의 직선 잔상을 남깁니다. 캐릭터의 이동 속도에 맞춰 궤적이 길어지고 짧게 사라집니다. 벽 때문에 이동이 짧아지면 잔상도 짧아지며, 공중 시전은 해당 높이를 따릅니다. 검사는 검정·노랑, 바디빌더는 흰색·하늘색을 사용하고 전직 전에는 잔상을 표시하지 않습니다. 기존 거리와 피해 판정은 유지합니다.

MP 포션은 두 마을의 상점에서 300원에 구매하며 MP를 최대 50 회복합니다. MP가 가득 찼으면 소모하지 않습니다. 인벤토리와 1–3번 슬롯에서 사용합니다. 일반 지역에는 쿨타임이 없고, 보스방에서는 전투 전후를 포함해 10초 쿨타임이 적용됩니다. 체력 물약과 별도로 관리되며 인벤토리/메뉴에서는 시간이 멈춥니다. 수량·슬롯·남은 보스방 쿨타임은 저장됩니다.

## 고양이 · 시위대

캐릭터 생성에서 고양이를 선택하면 빨간 장식이 없는 하늘색 후드 차림으로 시작합니다. A는 주먹질, Lv. 3 Q는 전방 할퀴기, Lv. 7 W는 뒤로 빠르게 뛰며 0.7초간 무적이 됩니다. 역삼역 1번 출구의 포탈에서 올림픽공원에 가서 Lv. 10에 빨간 두건을 두르고 화염병을 든 늘씬한 여우 교관 레드폭스에게 시위대로 전직하면, 플레이어 고양이는 빨간 리본과 목 두건을 착용합니다.

시위대 E는 최대 1초간 누를수록 화염병 사거리가 늘어납니다. 착탄 폭발로 범위 피해를 주고 3초간 불길을 남깁니다. Lv. 15 R **부정선거**는 투표함을 5초간 설치해 주변 적에게 휘날리는 투표지로 지속 피해를 줍니다. 기존 펭귄 저장 데이터와 전직 경로는 유지됩니다.

시위대 직업 특성은 점프 높이 +20%입니다. 일반 점프와 W의 뒤로 뛰기에 적용하며 체공 시간과 수평 이동 거리는 유지합니다. R의 피해 반경은 245에서 490으로 2배 확장했고 투표지 효과도 함께 넓혔습니다. 전직 후 대기·걷기·점프·A/Q/W/E/R 그림에는 빨간 귀 리본과 목 두건이 직접 그려져 있으며, 캐릭터 선택창과 상태창에도 같은 복장을 표시합니다. 전직 전 고양이는 기존 그림을 사용합니다.


## Lv. 31–40 사냥터와 A형

중앙 제어실 → 가속 실험구역(Lv.31–33) → 병기 조립라인(Lv.34–36) → 적색 동력로(Lv.37–40) → A형 격납고로 이어집니다. M 전체 지도와 상세 경로에도 반영했습니다. 마지막 빨간 포탈로 입장하고 A형 근처에서 F로 전투를 시작합니다.

Lv.35 A형은 HP 72,000, 플레이어 약 3배 크기의 회색·붉은색 로봇입니다. 칼날 베기, 기관총 연사, 붉게 충전한 후 돌진, 현재 위치를 각각 조준하는 0.5초 간격 4연속 폭격을 사용합니다. HP 40%에 처음 도달하면 7초 동안 무적이 되고 파란 안전지대를 표시합니다. 종료 시 영역 밖은 즉사하며, 고양이 W나 검사 E처럼 실제 무적 판정이 있는 기술로 회피할 수 있습니다. 피해 감소만으로는 막을 수 없습니다. 큰 피해로 이 단계를 건너뛸 수 없습니다.

HP 20%부터는 이동과 패턴 간격이 빨라지고 4초간 이동하며 회전하는 칼날, 넓은 원형 자기장 끌어당기기가 추가됩니다. 걷기·칼날·사격·충전·돌진·폭격·방어·회전·흡인마다 전용 프레임과 예고 효과가 있습니다. 처치 보상은 EXP 12,000, 6,000원, 에너지 코어 15개이며 재도전할 수 있습니다. 보스방 물약 규칙은 기존과 같습니다.

## 토끼 · 마법사

안경을 쓴 흰 토끼를 새 캐릭터로 선택할 수 있습니다. 원거리 마법 구체(A)는 짧은 거리의 첫 적에게 적중합니다. Q는 Lv.3에 배우는 보라색 전방 번개이며 W는 Lv.7부터 2초마다 사용할 수 있는 피해 없는 앞구르기입니다. Lv.10에 역삼역 1번 출구의 현토리에게 마법사로 전직하면 W가 전방 순간 이동으로 바뀝니다.

E는 주변 적에게 마력을 방출하고 3초간 최대 HP의 30%를 흡수하는 보호막을 부여합니다. 보호막은 실제 피해만큼 소모되고, 무적 효과는 아니므로 A형의 안전지대 즉사를 막지는 못합니다.

Lv.15 R ‘존경!’은 먼저 아군 대상 선택창을 엽니다. 현재는 본인 프로필 한 명을 선택할 수 있고, 취소 시 MP·쿨타임을 소모하지 않습니다. 확정하면 경례하며 10초간 이동속도·공격력·최대 HP +20%, 받는 피해 20% 감소를 얻습니다. 최대 HP 증가분만큼 현재 HP도 늘고, 만료 시 원래 최대 HP로 제한됩니다. 주위 360 범위 내 적과 보스는 3초간 ‘존경’ 상태로 공격력이 30% 감소합니다. 궁극기 MP는 35, 쿨타임은 35초입니다. 임시 강화는 저장 후 재접속 시 해제되며 쿨타임은 유지합니다.

16프레임 투명 모션 시트 `dist/assets/rabbit-motion.png`는 기본 image_gen으로 생성했습니다. 대기·양방향 걷기·점프·착지·구체·번개·구르기·순간 이동·보호막·경례·피격 모습을 포함합니다. 초상화는 같은 시트의 대기 프레임을 사용합니다. 정확한 생성 프롬프트는 `rabbit-art-prompts.json`에 있습니다.
